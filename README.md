
# 🚗 NitroArt - Car Poster Store Landing Page / Loja de Pôsteres de Carros

## 📝 Descrição | Description  
Landing Page desenvolvida para a **NitroArt**, uma loja especializada em pôsteres automotivos.  
O projeto foi criado com foco em um design moderno, responsivo e visualmente impactante, destacando coleções de pôsteres de carros clássicos, esportivos e personalizados.  

Landing Page developed for **NitroArt**, a store specialized in automotive posters.  
The project was built with a modern, responsive, and visually striking design, highlighting collections of classic, sports, and custom car posters.
